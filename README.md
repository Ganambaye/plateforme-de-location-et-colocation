# Tanal Sa Logement

Plateforme de logement étudiant au Sénégal — annonces, validation, boost et visites.

## Fonctionnalités

- Recherche de logements par type, quartier et prix
- Comptes étudiant, bailleur et administrateur
- Publication et validation d'annonces
- Mise en avant d'annonces (boost Premium / Standard)
- Prise de rendez-vous pour visite
- Messagerie entre étudiants et bailleurs
- Paiements via Wave et Orange Money

## Démarrage

```bash
npm start
```

L'application est disponible sur http://localhost:3000.
La base de données (`data/db.json`) est créée automatiquement au premier démarrage avec des données de démonstration.
